# 外部求解器适配器 (adapters)

本目录存放与外部 FEM 求解器的**松耦合**适配器。设计原则：

1. **只通过文件交换**：外部程序读取几何/材料 → 生成场图 → 本项目读取。
2. **不把外部求解器作为链接依赖**：避免许可证组合问题与重型部署。
3. **可复现**：每个适配器包含可版本化的输入模板与转换脚本。

## 计划模块

| 目录 | 功能 | 外部程序 | 阶段 |
| --- | --- | --- | --- |
| `magnet3d/` | 三维静磁铁磁场（含铁芯非线性） | Elmer (`StatMag`/`WhitneyAV`)，备选 GetDP/Radia | P2 |
| `rfcavity3d/` | RF 谐振腔本征模（ω、R/Q、Q、模式场） | Palace，备选 Elmer/GetDP | P3 |

## 输出格式

统一输出为 **openPMD/HDF5**（首选）或简单文本场图，由核心的 `CFieldMap3D`
读取。详见 `docs/ROADMAP.md`。

> P0 阶段仅建立目录与约定，具体实现从 P2 开始。
